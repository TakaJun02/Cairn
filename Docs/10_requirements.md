## 1. 機能要求

### FR-1 POI 推薦(やりたいこと 1)

- FR-1.1 対話からユーザーの好み・プロファイルを獲得・更新し、永続化できる
- FR-1.2 プロファイルに基づいて POI を推薦し、理由を添えて提示できる
- FR-1.3 リアルタイム情報(天気・混雑度)を推薦に反映できる

注: 推薦の方式(アルゴリズム・モデル・使うデータ)は要求では定めない。AI によるレコメンドは現在も最先端で研究されている深い領域であり、**設計段階でゼロベースの選択肢比較とユーザーとの議論を経て最良の手段を作り上げる**(現行実装の方式を既定としない)。

### FR-2 旅程プランニング(やりたいこと 2)

- FR-2.1 対話を通じて旅程を作成・編集できる
- FR-2.2 旅程に対する移動経路(車/徒歩)を提示できる(地図上での確認を含む)
- FR-2.3 旅程・プロファイルはセッションを跨いで保持され、続きから再開できる

注: 旅程に何を含めるか(訪問順のみか、時間帯・滞在時間・移動手段の割り付けまで含むか)、編集操作の粒度、プランニングの方式は要求では定めない。AI によるプランニングも最先端の研究領域であり、FR-1 と同様に設計段階の選択肢比較と議論で決める。

### FR-3 対話形式(やりたいこと 3)

- FR-3.1 ChatGPT / Gemini 同等の対話 UX。応答はストリーミング表示され、スレッド内の文脈を保った応答ができる
- FR-3.2 推薦・プランニングの操作は自然言語の対話で完結できる(専用フォーム入力を強制しない)
- FR-3.3 LLM 等の障害時は、その旨を明示して失敗する(正常応答への偽装・無言の握り潰しをしない)

### FR-4 オフライン観光ガイダンス(やりたいこと 4)

- FR-4.1 観光フェーズで必要な資材(音声・テキストの案内コンテンツ、地図表示資材)は計画フェーズに事前取得できる
- FR-4.2 観光中、インターネット接続なしで、現在地に応じた該当 POI の案内(音声主体)を提示できる
- FR-4.3 案内内容はリアルタイム情報(天気・混雑度)に応じて変化する
- FR-4.4 リアルタイム情報はサーバー側が保持し、LoRaWAN(相当)のダウンリンクとして端末へ届く。端末はオンライン復帰なしにこれを案内へ反映する
- FR-4.5 天気・混雑度の値はダミーでよい。ただし**サーバー上のシミュレータ**が生成・保持し、FR-4.4 の配送経路を必ず通す(端末内生成・HTTP 直接取得で代替しない)。実験のため、シナリオ(spot×時系列の値)を外部から制御・再現できる

### FR-5 ユーザー管理

- FR-5.1 研究用の簡易なユーザー登録・識別と、スレッド(会話)の復元

## 2. 非機能要求

| ID | 要求 | 補足 |
| --- | --- | --- |
| NFR-1 | **変更容易性を最優先**: 1 人の研究者が全体を把握でき、プロンプト・対話フロー・推薦ロジックを短いサイクルで差し替えられる | 研究プロトタイプとしての最重要特性 |
| NFR-2 | **再現性**: clone + 少数コマンドで全体を再現起動できる。ホスト固有パス・手作業手順・未文書の外部依存に依存しない | 実験再現・引き継ぎ |
| NFR-3 | **対話レイテンシ**: 最初のトークンが表示されるまでの時間を最小化する(ストリーミング前提) | LLM 呼び出しの直列化を避ける |
| NFR-4 | **事前生成は非同期ジョブ**: 案内コンテンツ生成(LLM+TTS)は分単位の処理であり、同期 HTTP に含めない。進捗を取得できる | |
| NFR-5 | **障害の局所化**: センサ・TTS・シミュレータなど周辺機能の停止で対話本体を止めない。縮退は必ず明示する | |
| NFR-6 | **秘密情報を Git に含めない** | `.env` は追跡外(確認済み)。値なしの `.env.example` を追跡する |
| NFR-7 | **計測可能性**: ターンごとの LLM 呼び出し回数・所要時間、ジョブの所要時間を記録でき、実験データとして取り出せる | |
| NFR-8 | 同時利用者は実験規模(〜数十)。それ以上のスケールは設計目標にしない | |
| NFR-9 | **狭帯域制約**: 観光フェーズで端末に届く情報は、LoRaWAN ダウンリンクの制約(数十バイト級ペイロード・低頻度・TTN フェアユース準拠)の中で設計する | FR-4.4/4.5 の配送経路 |

## 3. 実行環境の制約

- 生成 vLLM: ホスト GPU 上(OpenAI 互換 `/v1`)
- その他は単一ホストの docker compose
- 旧構成の埋め込み vLLM(別マシン)は、長期記憶のスコープ外化により**不要**
